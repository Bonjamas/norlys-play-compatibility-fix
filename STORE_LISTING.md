# Opera Add-ons listing draft

## Name
Norlys Play Compatibility Fix

## Category
Entertainment

## Summary
Unofficial compatibility fix for Norlys Play browser detection.

## Description
Norlys Play Compatibility Fix is an unofficial extension for users who experience a black or non-starting Norlys Play video player in Opera while the same stream works in Chrome.

The extension changes browser-identification information only for norlysplay.dk so the site receives a Chrome-compatible identity. It does not bypass DRM, subscriptions, authentication, geographic restrictions, or account permissions.

No analytics, telemetry, or personal data are collected.

This project is independent and is not affiliated with or endorsed by Norlys.
